STG-6 AQUASENTIAL AI — WEB PROJECT PROTOTYPE

Run:
1. Extract this ZIP.
2. Double-click start_windows.bat, or open index.html in Chrome/Edge.
3. No Python, backend, database, API key, or package installation is required for this front-end demo.

Features:
- Water intelligence overview dashboard and illustrative consumption chart
- Water Quality page with pH, turbidity, TDS and temperature explanations
- Sample-reading analyzer with transparent demo thresholds
- Usage Insights and conservation suggestions
- Alerts that can be marked reviewed
- Water guidance assistant with built-in answers for common questions
- Responsive desktop/mobile design

Important limitations:
This is a front-end prototype. Readings and alerts are illustrative sample data. It has no live sensors, real user accounts, backend, database, or live LLM connection. The assistant uses curated built-in guidance and cannot certify drinking-water safety.

Possible next stage:
Connect verified sensors or a data API, add backend/database and authentication, store historical readings, and integrate an LLM grounded in trustworthy water-safety references.

Technology: HTML, CSS, vanilla JavaScript.
